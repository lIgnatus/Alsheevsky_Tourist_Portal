# Туристический портал Альшеевского района

Рабочий прототип сайта для АНО РСЗИ «Триумф». Статический сайт без сборки: HTML, CSS и JavaScript, открывается двойным щелчком по `index.html` или с любого статического хостинга, в том числе GitHub Pages.

Все решения по сайту записаны в ТЗ проекта. Этот репозиторий содержит только сам прототип.

## Что внутри

| Страница | Что на ней |
|---|---|
| `index.html` | Заставка с горой, три ролика с дрона, пять плашек-гор, «Что посмотреть»: карта района, план поездки, Яндекс Карты и экскурсия |
| `index.html#o-brende`, `#partneram`, `#kontakty` | «О бренде», «Стать партнёром», «Контакты» поверх главной |
| `index.html#mesto/susaktau` | Карта с открытой карточкой места |
| `tury.html` | Туры: каталог с фильтрами и страница тура |
| `sobytiya.html` | Календарь событий |
| `filmy.html` | Фильмы: карусель, награды, герои со стопкой фото со съёмок и просмотром на весь экран, места съёмок |

## Как устроен код

```
assets/
  css/site.css        все стили
  js/common.js        шапка, подвал, логотип, окна верхней панели, формы, план в браузере
  js/home.js          заставка, видео, плашки гор
  js/planner.js       карта Leaflet, план поездки, экскурсия
  js/films.js         фильмы, стопка фото, просмотр на весь экран
  js/catalog.js       туры, сувениры, размещение
  js/events.js        календарь событий
  js/tamgi.js         маршрут по знакам
  js/data.js          все данные сайта
  js/posts.js         рассказы краеведов для экскурсии (собирается скриптом)

```

## Карта

Без ключа карта берёт подложку OSM France (данные OpenStreetMap, подписи по-русски), запасной вариант Esri. Для рабочего сайта зарегистрируйтесь на cloud.maptiler.com, создайте ключ, ограничьте его адресом сайта и впишите в `assets/js/data.js`:

```js
D.map = { maptilerKey:'ваш ключ', maptilerStyle:'streets-v2' };
```

## Экскурсия и рассказы краеведов

Экскурсия собирается из проверенных карточек мест, фильмов, знаков маршрута и рассказов краеведов из постов ВКонтакте. Рассказы готовит скрипт:

```
python tools/posts_index.py "../05 Источники/ВК — посты"
```

Скрипт находит абзацы о каждом месте, отсеивает объявления, архивные описи и версии, которые заказчик просил не использовать, и складывает кандидатов в `tools/posts_candidates.json`. В сайт попадают только цитаты, одобренные в `tools/posts_approved.json`. На рабочем сайте те же источники уйдут языковой модели на сервере, и она напишет рассказ только по ним, со ссылками на источники.
