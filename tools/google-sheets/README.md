# Заявки с сайта в Google-таблицу

Таблица: [База данных исходящих с сайта](https://docs.google.com/spreadsheets/d/1hZA29Xc2PSZeVxTydOkCGfebvBxGm1wpUnn3yKQ_ICQ/edit).
Каждая форма пишет на свой лист:

| Форма на сайте | Лист |
|---|---|
| Заявка на тур | Заявки на туры |
| Отзыв о туре, сувенире, жилье | Отзывы |
| Заказ сувенира | Заказы сувениров |
| Заявка на размещение | Заявки на размещение |
| «Узнать об открытии» у жилья, которое скоро откроется | Узнать об открытии |
| «Пригласить фильм» | Пригласить фильм |
| «Стать партнёром» | Стать партнёром |

В строке: дата и время, страница, объект (тур, товар, жильё) и все поля формы по их подписям.

## Подключение, 5 минут

1. Открыть таблицу → **Расширения → Apps Script**.
2. Удалить всё в файле `Код.gs` и вставить текст из `Code.gs` этой папки. Сохранить.
3. Выбрать функцию `setupSheets` → **Выполнить**. Google попросит доступ к таблице, разрешить. Появятся семь листов.
4. **Начать развёртывание → Новое развёртывание**, тип **Веб-приложение**:
   выполнять от имени **меня**, доступ **все**. Нажать **Начать развёртывание** и скопировать адрес вида `https://script.google.com/macros/s/…/exec`.
5. Вставить адрес в `assets/js/data.js`:
   ```js
   D.forms = { endpoint:'https://script.google.com/macros/s/…/exec' };
   ```
6. Проверить: открыть адрес в браузере, должно быть «Приёмник заявок работает». Отправить тестовую заявку с сайта, она появится на своём листе.

Если код скрипта меняли, нужно **Управление развёртываниями → Изменить → Новая версия**, адрес останется прежним.

## Важно

- Пока `endpoint` пустой, формы показывают «Заявка отправлена», но данные никуда не уходят.
- Сайт отправляет запрос в режиме `no-cors`: браузер не видит ответ скрипта, поэтому ошибки смотреть в Apps Script → **Выполнения**.
- Текст, который начинается с `=`, `+`, `-` или `@`, скрипт сохраняет с апострофом, чтобы его нельзя было выполнить как формулу.
